  - 슬라이드 1: 표지 (제목, 날짜, 팀명)

  - 슬라이드 3: 선수 성과 지표 (플레이어별 통계 비교표)
  - 슬라이드 4: 팀 전술 분석 (포메이션, 공수 전략)
  - 슬라이드 5: 경기 결과 트렌드 (라인 그래프, 시계열)
  - 슬라이드 6: 스카우팅 인텔리전스 (유망주 목록, 레이더 차트)
  - 슬라이드 7: 액션아이템 / 권고사항 (카드형 레이아웃, 담당자 태그)
  - 슬라이드 8: 다음 스프린트 목표 (타임라인/로드맵)
- 시각화 유형: KPI 카드, 레이더 차트, 신호등 테이블, 게이지 미터, 바 차트, 라인 그래프
- 특징: 어두운 배경(다크 테마)에 밝은 강조색(초록/파란/노란) 조합이 스포츠 분야 표준. 숫자 강조를 위한 큰 폰트 카드 레이아웃이 핵심.

## 레퍼런스 2: Football Scouting Report Presentation Structure (360 Scouting / PFSA)
- URL: https://360scouting.com/football-scouting-guide/reports/
- 보조 URL: https://the-footballanalyst.com/how-to-structure-a-professional-scouting-report/
- 슬라이드 수: 6~8장 (선수 개인 리포트 기준), 팀 레벨 리포트는 10~12장
- 구성 패턴:
  - 슬라이드 1: 표지 (선수명/팀명, 리포트 날짜, 스카우트 로고)
  - 슬라이드 2: 선수 프로필 요약 (포지션, 나이, 시장가치, 계약 만료일)
  - 슬라이드 3: 강점 분석 (불릿 포인트 + 아이콘, 키 스탯 하이라이트)
  - 슬라이드 4: 약점 및 개선 영역 (신호등 테이블 — 빨강/노랑/초록)
  - 슬라이드 5: 유사 선수 비교 (레이더 차트 오버레이)
  - 슬라이드 6: 스카우트 종합 평가 (X.X/10 점수 게이지 + 서술형 의견)
  - 슬라이드 7: 영입 권고사항 (액션카드 — 즉시 영입 / 모니터링 / 패스)
  - 슬라이드 8: 참고 데이터 출처 및 다음 관찰 일정
- 시각화 유형: 선수 사진+스탯 카드, 레이더(Spider) 차트, 신호등 상태 배지, 평점 게이지, 포지션 히트맵
- 특징: PFSA 공식 템플릿은 3가지 카테고리로 분류 — 포지션별(8종), 일반 리포트(3종), 매치 리포트(1종). 스카우트 팀 미팅에서는 일반 리포트 6~8장이 최적.

## 레퍼런스 3: Data Science Model Performance Sprint Review (InfoDiagram / SlideGeeks)
- URL: https://blog.infodiagram.com/2022/07/data-scientist-presentation-toolbox-5-handy-ppt-templates-to-use.html
- 보조 URL: https://www.slidegeeks.com/ppt/sprint-review
- 슬라이드 수: 8~10장 (스프린트 리뷰 표준)
- 구성 패턴:
  - 슬라이드 1: 표지 (스프린트 번호, 기간, 팀명)
  - 슬라이드 2: 이그제큐티브 서머리 (핵심 지표 3~5개, 결과 요약 한 문장)
  - 슬라이드 3: 모델 성능 현황표 (모델별 R²/AUC/Acc/MAE 비교, 신호등 상태)
  - 슬라이드 4: 어제(이전 스프린트) 달성/미달 체크리스트
  - 슬라이드 5: 문제 진단 — 가장 약한 모델 원인 분석 (원인→영향→해결책 카드)
  - 슬라이드 6: 오늘(이번 스프린트) 액션아이템 Top 3 (번호형 카드, 담당자/목표 지표/기한)
  - 슬라이드 7: 성능 트렌드 (모델 지표 시계열, 라인 차트)
  - 슬라이드 8: 종합 평가 및 로드맵 (X.X/5.0 게이지 + 마일스톤 타임라인)
  - 슬라이드 9: 대시보드 현황 (Streamlit 스크린샷 + URL)
- 시각화 유형: KPI 수치 카드, 신호등 테이블, 체크리스트(체크박스 아이콘), 원인-결과 다이어그램, 게이지 미터, 라인 트렌드 차트, 로드맵 타임라인
- 특징: 데이터 사이언스 결과 발표에서 가장 중요한 것은 "비즈니스 임팩트 우선 → 기술 상세 나중" 역피라미드 구조. 액션아이템은 반드시 SMART(구체적/측정가능/달성가능/관련성/기한) 형식으로 작성.

## 종합 권장 슬라이드 구성 (EPL 스카우트 데일리 브리핑용)

- 총 장수: **8장**
- 근거: 레퍼런스 1(스포츠 분석 8~12장) + 레퍼런스 2(스카우팅 리포트 6~8장) + 레퍼런스 3(스프린트 리뷰 8~10장) 교집합 → 8장이 가장 적합한 균형점
- 권장 순서:
  1. **표지** — 날짜(2026-05-23), 미팅 회차, EPL 스카우트팀 로고
  2. **이그제큐티브 서머리** — 김태현 종합 평가 X.X/5.0, 핵심 3줄 요약
  3. **ML 모델 성능 현황표** — 12개 모델 R²/AUC/Acc/MAE 신호등 테이블 (P7·P1 빨강 강조)
  4. **어제 액션아이템 달성 체크리스트** — 달성/미달/블로킹 구분
  5. **약한 모델 원인 진단** — P7 성장 곡선(R²=0.586), P1 경기 결과(Acc=54.79%) 집중 분석
  6. **오늘 액션아이템 Top 3** — 카드 레이아웃, 담당자/목표지표/기한 명시
  7. **김태현 스카우트 종합 평가** — X.X/5.0 게이지 + 5.0 달성 로드맵 타임라인
  8. **Streamlit 대시보드 현황** — 페이지 수, URL, 주요 기능 스크린샷
