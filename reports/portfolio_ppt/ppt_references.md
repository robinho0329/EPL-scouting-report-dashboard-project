## 레퍼런스 2: Football Scouting Report + Player Performance Deck (PFSA / The Football Analyst)

- **URL/출처:** https://the-footballanalyst.com/how-to-structure-a-professional-scouting-report/
- **보조 URL:** https://thepfsa.co.uk/scouting-material/ / https://360scouting.com/football-scouting-guide/reports/
- **슬라이드 수:** 6~8장 (포트폴리오 발표용 7장 최적)
- **구성 패턴:**
  - 슬라이드 1: 표지 (리포트 제목, 날짜, 스카우트 담당자, 클럽 로고)
  - 슬라이드 2: 선수/모델 프로필 요약 (포지션/유형, 핵심 지표 3개, 상태 배지)
  - 슬라이드 3: 강점 분석 (아이콘 + 불릿포인트, 주요 스탯 하이라이트, 퍼센타일 랭킹 컨텍스트)
  - 슬라이드 4: 약점 및 지속 미달 항목 분석 (신호등 테이블 — 연속 미달 집중 표시)
  - 슬라이드 5: 이적 시장 분석 (시장가치, 성장 곡선, 적응 예측 — xValue / Transfer Recommendation)
  - 슬라이드 6: 종합 평가 + 이적 권고 (X.X/5.0 게이지 + 서술형 권고사항 + 적합성 평가)
  - 슬라이드 7: 다음 액션 및 모니터링 일정 (타임라인 카드)
- **시각화 유형:** 스탯 카드, 레이더(Spider) 차트, 신호등 상태 배지, 평점 게이지(원형), 퍼센타일 바, 타임라인, 이적가치 트렌드 라인
- **특이사항:** 포트폴리오 발표 리허설용은 간결한 6~7장이 적합. 면접관/청중이 5분 이내에 전체를 파악할 수 있는 구성 필수. 연속 미달 항목(P1/P7)은 빨간 경고 배지로 명확히 표시. 이적 권고는 헤드 리크루터가 가장 먼저 확인하는 섹션으로 첫 페이지 근처에 배치 권장. PFSA 템플릿은 8개 포지션별 템플릿 + 3개 일반 리포트 + 1개 경기 리포트로 구성됨.

## 레퍼런스 3: Data Science Sprint Review / ML Model Performance Deck (SlideGeeks / SketchBubble / Traffic Light RAG)

- **URL/출처:** https://www.slidegeeks.com/ppt/sprint-review
- **보조 URL:** https://www.sketchbubble.com/en/presentation-traffic-lights-status-dashboard.html / https://blog.infodiagram.com/2019/12/traffic-light-graphics-project-management-presentation.html
- **슬라이드 수:** 8~10장 (모델 성능 리뷰 기준 9장 권장)
- **구성 패턴:**
  - 슬라이드 1: 표지 (스프린트/브리핑 번호, 기간, 팀명, 날짜)
  - 슬라이드 2: 이그제큐티브 서머리 (핵심 성과 3줄, 전체 상태 신호등)
  - 슬라이드 3: 모델 성능 현황표 (R²/AUC/Acc/MAE 매트릭스, 모델별 신호등 RAG 색상)
  - 슬라이드 4: 연속 미달 항목 원인 분석 (P1 Acc 54.79%, P7 R² 0.586 — 원인→영향→해결책 카드)
  - 슬라이드 5: 이전 스프린트 달성/미달 체크리스트 (체크박스 아이콘, 결과 요약)
  - 슬라이드 6: 이번 스프린트 액션아이템 Top 3 (번호형 카드, SMART 형식)
  - 슬라이드 7: 성능 트렌드 차트 (시계열 — 미달 구간 하이라이트)
  - 슬라이드 8: 포트폴리오 발표 준비 현황 (5분 시연 스크립트, 리허설 체크리스트)
  - 슬라이드 9: 종합 평가 게이지 + 로드맵 (X.X/5.0 + 5.0 달성 마일스톤)
- **시각화 유형:** KPI 수치 카드, 신호등 매트릭스 테이블(RAG), 원인-결과 다이어그램, 체크리스트(체크박스), 라인 트렌드 차트, 게이지 미터, 로드맵 타임라인
- **특이사항:** 스프린트 리뷰 4모듈 구조 (Sprint Status / Things to Demo / Quick Updates / What's Next). 연속 미달 항목은 별도 딥다이브 슬라이드 할당이 효과적. RAG(Red-Amber-Green) 신호등 시스템은 경영진이 즉시 상황을 파악할 수 있는 가장 효과적인 방법. 스탠드업 미팅은 어제 한 일 / 오늘 할 일 / 블로커 3구조가 표준이며 15분 이하로 제한.
