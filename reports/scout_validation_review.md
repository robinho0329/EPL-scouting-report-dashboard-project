## 2. 모델별 구체적 피드백

### S1: WAR 선수 레이팅 (2.0/5)

**R² = 0.49 (XGBoost test) -- 분산의 절반도 설명 못함**

문제점:

- **레귈론(Sergio Reguilon)이 DEF 1위(WAR 100.0)?** 맨유에서 임대로 온 백업 레프트백이 시즌 최고 수비수? 현실에서 이 결과를 영입 회의에 가져가면 신뢰를 잃는다.
- **Marcus Rashford 2024/25 FW 1위(WAR 100.0, Aston Villa)?** 라시포드는 24/25 시즌 맨유에서 방출 위기 수준의 퍼포먼스였고, 빌라 임대 후에도 기대 이하였다. 이걸 100점으로 찍는 모델은 근본적으로 뭔가 잘못되었다.
- **Trevoh Chalobah DEF 1위(WAR 100.0)?** 첼시에서 방출된 CB가 최고 수비수?
- **Martin Dubravka GK 1위(WAR 100.0)?** 닉 포프의 백업이 최고 골키퍼?
- **손흥민 MID 1위(WAR 100.0, 연속 2시즌)?** 손흥민이 좋은 선수인 건 맞지만, 24/25 시즌에 리그 최고 미드필더라는 건 과대평가다. 그리고 이 모델의 피처를 보면 `market_value`가 들어가 있는데, TM 데이터의 시장가치가 업데이트 시점에 따라 왜곡될 수 있다.

**피처 구성 문제:**
- `points`, `goal_diff` (팀 성적)가 개인 레이팅에 과도한 영향을 미침. 강팀 소속이면 자동으로 높은 레이팅을 받는 구조.
- `market_value`를 피처로 사용 -- 시장가치가 높으면 레이팅이 높아지는 순환 논리.
- `nineties`(출전 90분 횟수)를 사용하는데, 이러면 백업 선수가 적은 경기에서 강렬한 인상을 남기면 과대평가됨. 실제로 레귈론, 더브라프카, 찰로바 문제가 여기서 발생.

**히든젬 리스트:** 별도의 히든젬 파일(hidden_gems.parquet)이 있으나 내용 확인 불가. 다만 S1의 레이팅 자체가 신뢰할 수 없으므로, 여기서 파생된 히든젬 리스트도 신뢰할 수 없다.

**결론:** 스카우트 회의에서 사용하면 오히려 판단을 흐리게 한다. 근본적인 재설계 필요.

**문제점:**

- 이런 선수들의 predicted_next_z도 대부분 음수(-0.4~-0.5). "성장"이라고 하지만 여전히 평균 이하 수준으로 예측하는 것. 이건 의미 있는 성장이 아니다.

**결론:** S4보다 나아졌지만, 영입 판단에 직접 쓰기엔 부족. "이 선수가 내년에 더 좋아질까?"에 대해 74% 방향성 정확도는 나쁘지 않으나, 구체적인 성장 폭 예측은 신뢰하기 어렵다.

### P8: 이적 적응도 예측 (1.5/5)

**Best model: XGBoost, AUC = 0.70, val set = 43명, test set = 56명**

**치명적 문제: 데이터 부족**
- Validation set 43명, Test set 56명. 이 규모로는 어떤 통계적 결론도 내릴 수 없다.
- 전체 적응률이 69.7%. 모든 선수에 대해 "적응할 것이다"라고 찍으면 accuracy 70%. 모델이 하는 일이 거의 없다.
- Logistic Regression의 recall=1.0 (모든 선수를 "적응"으로 예측). 이건 모델이 아니라 그냥 다수 클래스 예측.

**피처 분석:**
- `g_a_per90_old` (이전 팀 공격 기여도)가 importance 0.214로 압도적 1위. 이건 상식이다: "이전 팀에서 잘 한 선수가 새 팀에서도 잘 할 가능성이 높다."
- `style_match_pct` (스타일 매칭)가 상위 피처에 없음. 이건 이적 적응 모델의 핵심이어야 하는데.

**예시 분석:**
- 3개 예시 모두 "적응 성공" 예측, 실제도 성공. 실패 사례가 없어서 모델의 변별력을 확인할 수 없음.
- 적응 실패를 잘 잡아내는 것이 이 모델의 핵심 가치인데, 그 부분이 검증되지 않음.

**결론:** 이적 적응 예측은 개념적으로 매우 유용하지만, 현재 구현은 데이터 부족과 클래스 불균형으로 인해 실무에서 참고할 수 없는 수준.

## 3. 종합 판단

### "이 프로젝트를 구단에 도입할 것인가?"

**조건부 Yes -- 단, 현재 상태 그대로는 No.**

현재 6개 모델 중 영입 회의에서 바로 사용할 수 있는 것은 **S3 유사선수 검색** 하나뿐이고, 그것조차 시장가치/계약 필터 없이는 반쪽짜리다. 나머지 모델들은 R²가 낮거나, 비현실적인 결과를 내거나, 데이터가 부족하다.

그러나 **인프라와 파이프라인의 가치는 인정한다.** 25시즌 EPL 데이터를 정제하고, 선수 프로필/팀 프로필/이적 데이터/매치 로그를 통합한 것 자체가 상당한 작업이다. 모델을 개선할 수 있는 토대는 갖춰져 있다.

### 가장 유용한 모델 TOP 3

1. **S3 유사선수 검색** -- 대안 선수 숏리스트 작성에 바로 활용 가능
2. **P7 성장곡선 (개선판)** -- 피크 에이지 분석과 방향성 예측은 참고 가능
3. **P6 시장가치 통합 모델** -- R²=0.87로 S2보다 훨씬 정확. 참고용으로 가치 있음

### 가장 개선이 필요한 모델

1. **S1 WAR 레이팅** -- 가장 심각. 레귈론 100점, 라시포드 100점은 모델의 근본적 결함을 보여줌.
   - 개선 방향: 팀 성적(points, goal_diff) 피처 제거 또는 비중 축소. market_value 피처 제거. 출전 시간 정규화 방법 변경(최소 출전 기준 900분 이상). xG/xA 기반 피처 추가.
2. **P8 이적 적응도** -- 개념은 좋지만 데이터 부족이 치명적.
   - 개선 방향: 이적 데이터를 2000년대 이후 전체로 확장. 다른 5대 리그 간 이적 데이터 포함. 적응 기준을 다단계(대성공/적응/실패/완전실패)로 세분화.
3. **S2 시장가치 포지션별** -- P6보다 오히려 퇴보.
   - 개선 방향: P6를 기본으로 하되, 포지션별 잔차 분석만 추가. 아카데미/유망주 프리미엄을 별도 피처로 반영. 계약 잔여 기간 피처 추가.

### 기존 스카우팅 툴 대비 차별점

| 항목 | Wyscout/InStat | TransferRoom | 이 프로젝트 |
|------|---------------|--------------|-------------|

| 영상 클립 | O | X | X |

**차별점이 있는 부분:** 유사선수 검색(25시즌 역대 데이터 기반), 성장 예측(개념적으로), 이적 적응 예측(개념적으로)

**차별점이 없는 부분:** 시장가치 예측은 TransferRoom의 딜 기반 데이터가 훨씬 정확. 선수 레이팅은 Wyscout의 자체 레이팅이나 CIES 풋볼 옵저바토리가 더 신뢰할 수 있음.

### 추가로 필요한 데이터/분석

1. **xG/xA 데이터**: 현재 goals/assists만 사용. xG 기반 과잉/과소 퍼포먼스 분석이 없으면 스카우트 도구로서 한계.
2. **부상 이력 데이터**: Reece James를 성장 유망주로 추천하는 것은 부상 데이터 부재 때문.
3. **계약 잔여 기간**: 시장가치의 핵심 결정 요인인데 빠져 있음.
4. **압박 스탯 (PPDA, 프레싱 강도)**: 현대 축구의 핵심 지표.
5. **패스 네트워크 데이터**: progressive passes, progressive carries 등.
6. **영상 기반 피처**: 포지셔닝, 오프더볼 무브먼트 (데이터 확보 어렵지만 장기적으로 필요).
7. **임금/계약 데이터**: 에버턴급 구단에게 wage structure는 이적료만큼 중요.

## 4. 개선 제안 (우선순위 순)

### 우선순위 1: S3 유사선수 검색 고도화 (가장 빠르게 실무 투입 가능)
- 시장가치 범위 필터 추가: "20M 파운드 이하에서 Saka와 유사한 선수"
- 나이 필터: "23세 이하에서 VVD와 유사한 CB"
- 계약 잔여 기간 필터 (데이터 확보 필요)
- 클러스터 아키타입별 "해당 클러스터에서 가장 저평가된 선수" 리스트 자동 생성
- 현재 실루엣 스코어 0.109 -> 피처 엔지니어링 개선으로 0.15 이상 목표

### 우선순위 2: S1 WAR 레이팅 전면 재설계
- 최소 출전 기준 도입 (시즌 900분 이상, 또는 15경기 이상 선발)
- market_value, points, goal_diff를 피처에서 제거
- 포지션별 가중치 적용: FW는 xG/골, MF는 key passes/progressive actions, DF는 aerial duels/tackles/interceptions, GK는 save%, PSxG
- 팀 강도 보정: "에버턴에서 7점짜리 퍼포먼스"와 "맨시티에서 7점짜리 퍼포먼스"의 난이도 차이 반영
- 100점 만점이 아닌 상대적 순위(백분위)로 전환

### 우선순위 3: S6 하락 감지 모델 완성
- results_summary.json 생성, 모델 성능 지표 공개
- 30세 이상 선수에 대한 "향후 2시즌 퍼포먼스 하락 확률" 예측
- 방출/재계약 판단용 리스크 점수 (High/Medium/Low) 생성
- 연봉 대비 퍼포먼스 효율 지표와 결합

### 우선순위 4: P8 이적 적응도 데이터 확장
- 현재 852건 -> 최소 3000건 이상으로 확대 (Championship 포함, 다른 리그 이적 포함)
- 적응 실패 사례를 의도적으로 오버샘플링하여 클래스 균형 확보
- 전술 스타일 매칭 피처 강화 (현재 style_match_pct가 top feature에도 없음)
- "에버턴에서 본 선수를 영입하면 우리 팀에 적응할 확률"을 시뮬레이션할 수 있도록

### 우선순위 5: xG/xA 기반 피처 추가 (전체 모델 개선)
- FBref에서 xG, xA, npxG, SCA, GCA 데이터 크롤링
- 모든 공격 모델(S1, S2, S4, P7)에 xG overperformance/underperformance 피처 추가
- "xG 대비 골이 적은 선수 = 운이 나빴을 뿐, 실력은 있다" -> 진짜 저평가 선수 발굴

### 우선순위 6: 대시보드 통합
- 현재 Streamlit 대시보드가 있으나, 스카우트 모델 결과가 통합되어 있지 않음
- "선수 이름 검색 -> 레이팅/유사선수/성장예측/시장가치 한눈에 보기" 화면 필요
- 숏리스트 관리 기능 (관심 선수 저장, 메모, 우선순위 태깅)

## 최종 한줄 평가

**데이터 파이프라인과 인프라는 80점, 모델 품질은 35점, 실무 활용성은 20점.**

S3 유사선수 검색을 중심으로 빠르게 실무 투입하고, 나머지 모델은 위 개선 사항을 반영한 후 재검증이 필요하다. 현재 상태에서 "이 모델이 추천하는 선수를 영입하겠다"고 보드에 제안할 수는 없다. 하지만 "이 데이터를 기반으로 우리만의 스카우팅 인텔리전스를 만들 수 있다"는 가능성은 분명히 있다.
