## S5. 이적 적응 예측 모델 (Transfer Adaptation v2)

### 점수: 3.0 / 5.0 -- FAIL

### v1 대비 개선사항
- **3-class 라벨링**: success/partial/failure. v1의 이진 분류보다 풍부한 정보.
- **AUC 개선**: failure AUC = 0.816 (Ensemble), 0.867 (GBM). v1의 0.717 대비 유의미 상승.
- **피처 확대**: 28 -> 45. ELO gap, style compatibility, position scarcity, career trajectory 추가.
- **데이터 확대**: 총 936건 (v1 대비 증가). 300분 임계값 (v1=450).
- **시간 기반 분리**: test = 2023/24 + 2024/25.

### 검증 결과

**샘플 수 문제 -- 여전히 치명적**:
- **test = 68건, 그 중 failure = 5건**: "failure class has only 5 samples in test". 5건으로 AUC를 논하는 건 통계적으로 무의미. AUC=0.816이든 0.500이든 5건에서는 1건 차이로 크게 흔들린다.
- val = 51건. 이것도 너무 적다.
- train = 817건은 3-class 분류에 최소한이지만, failure=124건(13.2%)으로 클래스 불균형 심각.

**모델 간 불일치 -- 불안정성 증거**:
- GBM test accuracy = 0.706, XGBoost = 0.559, Ensemble = 0.618. 같은 데이터인데 모델 간 15%p 차이.
- GBM val에서 failure_f1 = 0.0 (failure를 하나도 못 맞춤), test에서 0.444. val/test 간 극단적 불일치 = 과적합 의심.
- LogisticReg val failure_auc = 0.48 (랜덤 이하), test = 0.80. 이것도 불안정.

**Confusion Matrix 분석 (Ensemble test)**:
```
           Predicted: fail  partial  success
Actual fail:    2      3       0
Actual partial: 3     21       5
Actual success: 2     13      19
```
- failure 5건 중 2건 정확 = 40% recall. "이 이적은 실패할 것이다"라고 5번 예측하면 2번 맞고 3번 틀리는 수준. 스카우트가 감으로 해도 이 정도는 한다.
- partial이 success로 분류되는 것보다 success가 partial로 분류되는 게 더 많음(13건). 보수적 편향.

**피처 중요도**:
- min_share_pct_old(7.1%), g_a_p90_old(4.7%), ast_p90_old(3.7%): 전 팀 성적 위주. 합리적.
- style_match_pct, elo_gap, pos_competition 등 새 피처가 상위에 포함 -- 방향은 좋다.

### 여전히 남은 문제
1. **test failure = 5건**: 통계적으로 무의미한 평가. AUC 숫자를 믿을 수 없음
2. **val/test 불일치**: GBM val failure_f1=0.0 vs test=0.444. 모델 불안정
3. **전체 accuracy 62%**: 3-class에서 baseline(가장 빈번한 클래스=partial=45%) 대비 17%p 개선. 나쁘진 않지만 의사결정에 쓰기엔 부족
4. **45 피처 / 817 train**: 피처 대비 데이터 비율이 빠듯. 과적합 위험

### 실무 활용 가능?
방향은 옳다. ELO gap, style match 등의 피처 설계가 축구 지식을 반영하고 있다. 하지만 **failure 5건으로 "이 이적 실패할 겁니다"라고 이사회에 보고하면 "그 5건이 뭔데?"라는 질문에 답할 수 없다. FAIL.**

### 통과를 위한 수정사항
- 유럽 5대 리그로 데이터 확대하여 최소 test failure 30건 이상 확보
- 또는 2-class로 복귀 (success vs not-success)하여 클래스 불균형 완화
- Leave-One-Season-Out CV로 안정성 검증
- 피처 30개 이하로 축소 (Lasso/RFE 사용)

## S6. 하락 감지 모델 (Decline Detection v1)

### 점수: 3.0 / 5.0 -- FAIL

### 모델 개요 (신규)
- AUC = 0.8324 (XGBoost). 4개 모델 중 최고.
- 21개 피처, 13,343 샘플 (train 11,510 / val 1,253 / test 580)
- 하락 정의: 성과 0.5 SD 이상 하락 OR 출전 30% 이상 감소
- 시간 분리: train < 2021, val = 2021-22, test >= 2023

### 검증 결과 (축구 상식 체크)

**워치리스트 -- 심각한 문제들**:
- **Cole Palmer (21세, MID, decline_prob=0.883)**: 2023/24 시즌 EPL 최고의 선수 중 하나가 "하락 가능성 88%"? perf_score=3.39, perf_slope=1.21 (급성장 중)인 선수를. 이건 **"갑자기 잘한 선수는 다음 시즌 평균 회귀한다"를 하락으로 분류**하는 것. 평균 회귀 =/= 하락.
- **Morgan Rogers (21세, MID, 0.883)**: Aston Villa에서 브레이크 시즌을 보낸 21세 유망주가 88% 하락?
- **Conor Bradley (20세, DEF, Liverpool, 0.859)**: 리버풀의 미래 우측 풀백이 86% 하락 예측?
- **Armando Broja (21세, FWD, 0.912)**: 이건 실제로 맞았다 -- Broja는 부상과 부진이 이어졌다. 하지만 이유가 맞는 건 아님 (모델은 부상 예측이 아니라 "젊은 FW는 하락"으로 학습).
- **Jhon Duran (19세, Unknown pos, 0.905)**: pos_group이 "Unknown"인 19세 선수가 하락 1위권? 포지션 매핑 실패 + 나이 무관한 높은 확률.
- **Kevin De Bruyne (32세, 0.891)**: 이건 합리적. 32세 부상 잦은 MID의 하락 예측은 스카우트 직관과 일치.
- **Callum Wilson (31세, 0.851)**: 역시 합리적. 부상이 잦은 31세 FW.

**Iron Men 리스트**:
- Alisson, Ederson, Raya, Vicario, Pickford, Onana: **전부 GK**가 상위 6명. "하락 안 할 선수" = GK라는 편향.
- Saka(0.236), Martinelli(0.250), Saliba(0.252), Mainoo(0.269): 이건 합리적.

**나이-포지션 하락률 곡선**:
- DEF: 18-22(35%) -> 23-26(41%) -> 27-30(43%) -> 31-35(48%). 단조 증가. 합리적.
- MID: 18-22(38%) -> ... -> 31-35(56%). 합리적.
- FWD: 18-22(35%) -> ... -> 31-35(55%) -> 36-40(70%). 합리적.
- **GK: 18-22(18%) -> 23-26(32%) -> 27-30(37%) -> 31-35(32%) -> 36-40(32%)**. GK가 31-35에서 오히려 하락률 감소? 이건 "GK는 나이 들어도 괜찮다"는 현실 반영이긴 한데, 모델이 GK를 일괄적으로 "안전"으로 분류하는 편향의 원인.

**피처 중요도 문제**:
- 상위 4개 피처: pos_DEF(0.133), pos_FWD(0.104), perf_score(0.099), pos_MID(0.093). **포지션 원핫이 3개나 상위 4위 안에**. 이건 "어떤 포지션이냐"가 실제 퍼포먼스 변화보다 중요하다는 뜻. 포지션이 하락을 "예측"하는 게 아니라, 포지션별 base rate 차이를 학습한 것.
- perf_slope(0.036)가 10위권 밖은 나쁘지 않다. 하지만 age(0.036)나 peak_minus_current가 피처 목록에 있는데도 pos가 압도적이라 모델이 개인별 궤적보다 포지션 통계에 의존.

### 여전히 남은 문제
1. **"급성장 후 평균 회귀" = 하락으로 분류**: Cole Palmer, Morgan Rogers, Conor Bradley 등. 브레이크 시즌 후 약간의 조정은 자연스러운데, 이걸 "하락"으로 경고하면 스카우트가 유망주를 놓친다.
2. **포지션 피처 과다 의존**: pos_DEF/FWD/MID/GK가 합산 importance 37%. 개인 궤적 피처가 묻힘.
3. **워치리스트에 21세 이하 유망주 다수**: Broja, Palmer, Rogers, Bradley, Duran. 하락 워치리스트의 목적은 "쇠퇴하는 베테랑 경고"인데, 유망주가 점령.
4. **Iron Men에 GK 독점**: 하락 안 하는 선수 = GK라는 편향.
5. **Jhon Duran pos_group="Unknown"**: 데이터 클리닝 미비.
6. **peak_minus_current 대부분 0.0**: 이 피처가 제대로 계산됐는지 의문. 워치리스트 20명 중 16명이 0.0.

### 실무 활용 가능?
AUC=0.83은 괜찮은 숫자지만, 워치리스트를 보면 "Cole Palmer가 하락합니다"가 나온다. **이걸 이사회에 보여주면 "이 모델 누가 만들었어?"라는 소리 듣는다. FAIL.**

### 통과를 위한 수정사항
- "하락" 정의에서 **"전 시즌 perf_z > 1.0인 선수의 평균 회귀"를 제외**. 브레이크 시즌 후 정상화는 하락이 아님.
- 포지션 원핫 피처 제거하고 포지션별 모델 분리 (또는 포지션 임베딩으로 교체)
- 워치리스트에 연령 25세 이상 필터 추가 (또는 연령대별 분리 출력)
- peak_minus_current 피처 재검증 (0.0이 16/20이면 계산 오류 가능성)
- "Unknown" 포지션 데이터 클리닝
