### 5-2. P8 — XGBoost 3.x `use_label_encoder` 제거

**에러 내용:**
```
[INFO] XGBoost Classifier 학습
Traceback (most recent call last):
...
TypeError: XGBClassifier.__init__() got an unexpected keyword argument 'use_label_encoder'
```

**원인:** `use_label_encoder=False` 파라미터는 XGBoost **1.x 시절** 필요했던 옵션입니다. XGBoost **2.0+에서 제거**됐으며, GitHub Actions 환경(xgboost==3.2.0)에서 해당 파라미터를 넘기면 `TypeError`가 발생합니다.

**수정 내용:** `xgb.XGBClassifier(...)` 호출에서 `use_label_encoder=False` 한 줄 제거. 나머지 파라미터는 유지:
- `scale_pos_weight=pos_weight` (동적 계산: n_neg/n_pos ≈ 0.39) ✅ 유지
- `eval_metric="auc"`, `early_stopping_rounds=50` ✅ 유지

**김태현:** `scale_pos_weight`는 이미 들어가 있었습니까?

**Marcus:** 네, 어제 오전 세션에서 추가돼 있었습니다. `pos_weight = float((y_train == 0).sum()) / max((y_train == 1).sum(), 1)`로 동적 계산됩니다. 데이터상 적응 성공(1)=약 75%, 실패(0)=약 25%이므로 `scale_pos_weight ≈ 0.33~0.39`입니다. 소수 클래스(실패)를 상대적으로 더 학습합니다.
