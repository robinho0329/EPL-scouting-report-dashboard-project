## 1. 팀 토론

### 1-1. P7 v5 — 설계 리뷰

**Marcus:** P7 v5의 핵심 변경 사항을 보고합니다.

v4에서 delta(변화량) 학습이 v3 스태킹(R²=0.6089) 대비 성능 하락(R²=0.5477)을 유발했습니다. 원인 분석: 변화량 예측은 타겟 분산이 원래 값 예측보다 크기 때문에 모델이 더 많은 노이즈를 학습합니다. 그리고 `current_ac + pred_delta` 역변환 과정에서 오차가 누적됩니다.

v5에서는 타겟을 절대값(`target_ac_raw`)으로 복원했고 v4에서 추가한 10개 피처(lag4, gc_trend_3yr, war_ratio, age_vs_peak_lag1, war_ma4, ac_z_trend3 등)는 계승했습니다. 핵심 개선은 OOF 교차검증을 기존 `KFold(shuffle=True)`에서 `GroupKFold(n=5, groups=season_year)`로 교체한 것입니다.

**김태현:** GroupKFold가 정확히 어떤 의미입니까?

**Marcus:** shuffle=True KFold는 2020년 선수 데이터가 2015년 데이터의 validation fold로 들어가는 경우가 생깁니다. 축구 선수 성장 데이터는 시간 의존성이 강해서 — 2015시즌을 보고 2020시즌을 예측하는 건 맞지만 반대는 데이터 누수입니다. GroupKFold는 시즌 단위로 fold를 나눠 항상 과거 시즌으로 미래 시즌을 예측하는 구조를 유지합니다.

**김태현:** 그게 더 현실적이군요. 실제 스카우트도 과거 데이터로만 미래를 예측합니다. v5 결과는 언제 나옵니까?

**Marcus:** 내일 09:15 KST GitHub Actions에서 자동 실행됩니다. MODEL_MAP을 train_v5.py로 업데이트했으니 내일 아침 미팅에서 R²를 확인할 수 있습니다.

### 1-2. P8 이적 리스크 필터 UI — 시연

**Marcus:** `scout_transfer.py` P8 섹션 하단에 세 가지 UI 블록을 추가했습니다.

첫째, 고위험 필터입니다. 나이 슬라이더(기본 30세)와 전술 거리 슬라이더(기본 0.02)로 실시간 필터링합니다. 메트릭으로 고위험 건수, 평균 성공률, 평균 전술 거리를 보여줍니다.

둘째, 필터 결과 테이블 — 선수명, 이전팀, 이적팀, 나이, 전술 거리, 성공 확률, 리스크 배지가 나옵니다.

셋째, 파레토 프론티어 산점도 — x축은 전술 거리, y축은 성공 확률, 마커 크기는 시장가치입니다. 별표(⭐)로 파레토 최적 선수를 강조 표시합니다 — 같은 전술 거리에서 가장 성공률 높은 선수들입니다.

**김태현:** 파레토 프론티어가 실용적입니다. "30M 이하에서 적응 성공률 가장 높은 선수"를 찾으려면 이 차트 우상단을 보면 되는 거죠? 기준선(빨간 세로선 0.02, 초록 가로선 75%)도 직관적입니다. 영입 회의에서 바로 쓸 수 있겠습니다.

**Marcus:** 맞습니다. 좌상단(전술거리 낮고 성공률 높음) = 최우선 영입 후보, 우하단(전술거리 높고 성공률 낮음) = 적응 실패 위험 구역입니다.

### 1-3. P1 오즈 피처 — 조사 결과

**Marcus:** Football-Data.co.uk 데이터 구조를 확인했습니다. 시즌별 E0.csv 파일에 `B365H/D/A` (Bet365 오즈) 컬럼이 있고, 2000/01 시즌부터 2024/25 시즌까지 무료로 제공합니다.

**김태현:** 무승부 예측 개선에 시장 확률이 얼마나 효과적입니까?

**Marcus:** 학술 연구에 따르면 북메이커 오즈는 무승부 내재 확률을 약 26-28%로 잡는데, 이 자체가 피처로 들어가면 모델이 "시장이 무승부를 어떻게 보는가"를 학습합니다. 특히 `draw_market_prob`이 높은 경기(0.28 이상)에서 모델이 D 클래스를 더 적극적으로 예측하게 됩니다. val confusion matrix의 D 정확도(현재 12%)가 크게 개선될 것으로 기대합니다.
